# 🍓 SUARA GEN Z — Bukan Lembek, Cuma Realistis!

Platform web interaktif yang membela Generasi Z atas stereotip dan *bullyan* generasi terdahulu (Boomer, Gen X, dsb.) dengan data objektif, logika dingin, dan gaya komunikasi yang segar (*neo-brutalist aesthetic*).

---

## 🌟 Fitur Utama

1. **🔥 Katalog Klarifikasi: 5 Mitos Terbesar Gen Z**
   - *Mitos 1:* "Gen Z Lembek & Dikit-dikit Kena Mental" (Fakta: Memutus rantai *generational trauma* & melek literasi psikologi).
   - *Mitos 2:* "Gen Z Kutu Loncat & Gak Loyal" (Fakta: Kenaikan internal kalah dengan inflasi, resiprokal kerja era layoff).
   - *Mitos 3:* "Susah Beli Rumah karena Kebanyakan Jajan Kopi & Nonton Konser" (Fakta: Rasio harga rumah vs UMR melonjak gila-gilaan).
   - *Mitos 4:* "Jam 5 Teng Langsung Pulang / Gak Mau Lembur" (Fakta: Efisiensi kerja digital modern & penolakan *toxic burnout*).
   - *Mitos 5:* "Sok Keren Campur Bahasa Inggris / Jaksel" (Fakta: Bahasa berevolusi & adaptasi global borderless).
   - Dilengkapi sistem filter kategori interaktif.

2. **☕ Simulator Ilmiah: "Puasa Es Kopi Susu vs Beli Rumah"**
   - Slider dinamis harga jajan harian, harga rumah, dan target DP.
   - Menghitung secara matematis berapa dekade seseorang harus puasa ngopi cuma demi DP atau beli rumah *cash*.

3. **💬 Generator Jawaban Skakmat**
   - Menjawab pertanyaan klise di acara keluarga / kantor ("Kapan nikah?", "Kenapa jam 5 pulang?", dsb.).
   - 3 Mode Gaya Bicara:
     - 😇 *Santun & Bijak* (Aman dari dicoret dari KK)
     - 📊 *Data & Logika* (Argumen ilmiah berbasis riset)
     - 🔥 *Savage & Pedas* (Jawaban menusuk berkelas)
   - Tombol salin teks satu-klik dengan notifikasi toast.

4. **🎯 Bingo Bullyan Generasi**
   - Grid 3x3 kalimat legendaris nyinyiran generasi tua.
   - Skor otomatis & tingkatan status kebal batin (mulai dari *Pendekar Baru Lulus* hingga *Vibranium Level Gen Z*).
   - Efek ledakan confetti saat mencapai pencapaian tertentu!

5. **📢 Dinding Suara & Curhat (Wall of Voices)**
   - Curhatan realistis generasi muda (Fresh grad, sandwich generation, remote worker).
   - Fitur kirim curhatan anonim baru (tersimpan di `localStorage` peramban).
   - Sistem reaksi Like interaktif.

6. **💌 Surat Terbuka untuk Generasi Sebelumnya**
   - Pesan rekonsiliasi dan empati tanpa permusuhan: mengingatkan bahwa medan perang ekonomi, teknologi, dan iklim masa kini sudah jauh berbeda.
   - Tombol integrasi berbagi pesan ke WhatsApp keluarga.

7. **🌓 Tema Gelap / Terang (Dark & Light Mode)**
   - Mendukung preferensi sistem operasi dan penyimpanan pilihan pengguna.

## 🚀 Cara Menjalankan

Web ini bersifat **100% standalone** (HTML, CSS, JS modern dengan Tailwind CSS & Lucide Icons via CDN), tanpa perlu proses build yang rumit.

### Opsi 1: Server Python (Sudah Berjalan di Background)
```bash
python3 -m http.server 5000
```
Buka browser di: `http://localhost:5000`

### Opsi 2: Buka Langsung File HTML
Buka file `index.html` langsung di browser Chrome, Firefox, Safari, atau Edge favoritmu.

### Opsi 3: Deploy Online Gratis
Bisa langsung di-deploy ke:
- **GitHub Pages** (cukup push file ke repo GitHub dan aktifkan Pages).
- **Vercel** atau **Netlify** (drag and drop folder proyek ini).
